## 🎯 Sobre o Projeto

O **CestaCerta** é um sistema para ajudar você a organizar listas de compras e comparar preços cadastrados em diferentes mercados. A proposta é facilitar o planejamento da compra, mostrando onde os produtos da lista podem ser encontrados e quais opções têm menor custo.

---

## 🚀 O que o sistema faz

- 📝 **Monta e organiza listas de compras**, que ficam salvas no navegador usado.
- 🔎 **Busca produtos e consulta preços cadastrados**, com filtros por mercado e categoria.
- 📦 **Compara a mesma marca e apresentação** do produto para tornar a comparação mais clara.
- 🧮 **Mostra alternativas de compra:** a opção mais econômica em uma loja ou uma combinação de até três lojas.
- ⚠️ **Sinaliza itens sem preço disponível**, para que não sejam confundidos com itens incluídos no total.
- 🏪 **Oferece um painel para organizar mercados e registrar/revisar encartes manualmente.** O cadastro de ofertas a partir dos encartes ainda não é automático.

---

## 🛍️ Como funciona

1. Crie uma lista com os produtos que pretende comprar.
2. Consulte os preços disponíveis para esses produtos.
3. Compare as opções por mercado e veja a melhor alternativa para a sua lista.

---

> **Atenção:** o catálogo disponível atualmente contém dados fictícios de demonstração. Os valores servem apenas para mostrar como o sistema funciona; não são preços reais nem ofertas vigentes.
